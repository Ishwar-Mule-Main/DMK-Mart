    63→// ─── FINANCIAL YEAR REGISTRY (Apr–Mar book years per firm) ───────
    64→// A year "exists" for a firm only when a row is present here. The app
    65→// auto-creates the current year on boot when autoCreateFy is ON; when
    66→// it is OFF (or creation fails) every section stays locked behind the
    67→// FY gate until the owner opens the new year's books.

    69→model FinancialYear {
    70→  id          String   @id @default(cuid())
    71→  firmId      String
    72→  firm        Firm     @relation(fields: [firmId], references: [id], onDelete: Cascade)

    75→  endDate     DateTime // Mar 31 of the closing year

    78→  createdAt   DateTime @default(now())
    79→
    80→  @@unique([firmId, label])
    81→  @@index([firmId, startDate])
